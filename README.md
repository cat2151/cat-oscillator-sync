## Quick Start

### Try in Browser (Easiest!)

**[→ Open GitHub Pages Demo](https://cat2151.github.io/cat-oscillator-sync/)**

No installation required!

### Python Version (Recommended)

```bash
pipx install git+https://github.com/cat2151/cat-oscillator-sync
cat-oscillator-sync-simple  # Simple version
cat-oscillator-sync-smooth  # Smooth version
```

### Other Implementations

- **Rust**: Fast and efficient implementation
- **Go (Pure Go - Oto)**: No C compiler required ⭐ Recommended
- **Go (PortAudio)**: High performance with Zig cc
- **TypeScript (Browser)**: Web Audio API implementation
- **TypeScript (CLI)**: Node.js CLI version (Windows only)
