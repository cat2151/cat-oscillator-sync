# Cat Oscillator Sync - Browser Edition

🎵 This directory contains the built version of the browser-based oscillator hard sync synthesizer.

Visit: [https://cat2151.github.io/cat-oscillator-sync/](https://cat2151.github.io/cat-oscillator-sync/)

## 📝 About

This is the **production build** of the TypeScript browser implementation, automatically deployed via GitHub Actions.

### Features

- **Simple Version**: Step-wise frequency changes (8ms polling)
- **Smooth Version**: Exponential smoothing for fluid frequency transitions (16ms time constant)
- **Mouse Control**: X-axis controls master frequency (40-600 Hz), Y-axis controls slave frequency (100-2000 Hz)
- **Hard Sync**: Classic oscillator sync synthesis technique

## 🔧 Technical Details

- **Framework**: TypeScript + Vite
- **Audio Engine**: Web Audio API with AudioWorkletProcessor
- **Sample Rate**: 48000 Hz
- **Waveform**: Sawtooth
- **Browser Support**: Chrome 66+, Firefox 76+, Edge 79+ (Windows)
