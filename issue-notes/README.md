# Issue Notes Directory

このディレクトリには、各issueに関連するドキュメントが整理されています。

## 命名規則

ファイル名は以下の形式で命名されています：
```
{issue番号}_{説明}.md
```

例：
- `2_RUST_IMPLEMENTATION_PLAN.md` - Issue 2に関連するRust実装計画書
- `34_BUILD_AND_RUN.md` - Issue 34に関連するビルド＆実行ガイド
