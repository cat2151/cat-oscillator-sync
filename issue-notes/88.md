### 主な特徴

1. **npm bundleに対応**
   - webpack, rollup, esbuildなどの主要バンドラーで動作
   - ES modulesとして実装
   - TypeScript型定義ファイル(.d.ts)を自動生成

2. **Obsidianプラグインに最適化**
   - Electron環境（Obsidianのベース）で動作
   - AudioWorkletをBlob URLとして動的ロード
   - 外部依存なし（Web Audio APIのみ使用）

3. **使いやすいAPI**
   - `SimpleSynth` - ステップ状の周波数変化
   - `SmoothSynth` - スムーズな周波数変化（指数関数スムージング）
   - `mapToFrequency()` - マウス位置を周波数にマップするユーティリティ関数
   - `DEFAULT_FREQUENCY_RANGES` - デフォルトの周波数範囲定数

### 技術的な工夫

**AudioWorkletのバンドル対応**

従来のブラウザ版では、AudioWorkletを別ファイルとして読み込んでいましたが、ライブラリ版では以下の工夫により、bundlerでのバンドルを可能にしました：

1. AudioWorkletのコードを文字列として保存
2. 実行時にBlob URLを作成して動的にロード
3. これにより、single bundleファイルでの配布が可能

```typescript
// ワークレットコードを文字列として保存
export const SimpleWorkletProcessor = `
class SimpleWorkletProcessor extends AudioWorkletProcessor {
  // ... processor code ...
}
registerProcessor('simple-worklet-processor', SimpleWorkletProcessor);
`;

// 実行時にBlob URLから読み込み
const blob = new Blob([this.workletCode], { type: 'application/javascript' });
const workletUrl = URL.createObjectURL(blob);
await this.audioContext.audioWorklet.addModule(workletUrl);
URL.revokeObjectURL(workletUrl);
```

## 使用方法

### インストール

```bash
npm install cat-oscillator-sync-lib
```

### 基本的な使い方

```typescript
import { SimpleSynth } from 'cat-oscillator-sync-lib';

const synth = new SimpleSynth();
await synth.start();
synth.updateFrequencies(freqMaster, freqSlave);
synth.stop();
```
